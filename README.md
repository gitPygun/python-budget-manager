# Python Budget Manager

## About the Project
Python Budget Manager is a simple command-line application that helps users track their income, expenses, and remaining balance. It allows users to organize transactions by category and save their financial records using JSON file storage.

## Features
- Add income transactions
- Record expenses
- Categorize transactions
- View transaction history
- Calculate total income and expenses
- Display remaining balance
- Save transactions automatically to a JSON file

## Technologies Used
- Python 3
- JSON for data storage

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python3 budget_manager.py`

5. Follow the menu instructions to manage your budget.
